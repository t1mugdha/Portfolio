# Tahmidul Islam Mugdha — 3D Portfolio

My portfolio as a small gaming room you can walk around in the browser. Click the monitor for projects, the corkboard for experience, the pegboard for skills, the shelf for an about page, the arcade for a mini-game and the mailbox to get in touch.

Built with React, TypeScript, Three.js / React Three Fiber and Vite. The room was modelled in Blender with its lighting baked into a single texture, so it stays light enough for a laptop or phone.

## Run locally

```bash
npm install
npm run dev
```

`npm run build` makes a production build in `dist/`.

## Where things are

- `src/content/` — all the text: profile, projects, experience, skills
- `src/scene/` — the 3D room, camera, lights, screens and effects
- `src/ui/` — panels, menus, the cursor and the plain (non-3D) version
- `public/room/` — the room model and its baked lighting
- `public/projects/` — project images
